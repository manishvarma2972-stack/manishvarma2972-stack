## 🌟 Featured Engineering Projects

### 1. [CallMate AI](https://github.com/manishvarma2972-stack/CallMate-AI) &bull; Production Personal AI Voice Receptionist
*Autonomous voice receptionist agent powered by Gemini Live bidirectional streaming and FastAPI.*

- **Problem**: Traditional IVRs and voicemail systems are rigid, robotic, and cannot converse or screen inquiries with contextual intelligence.
- **Solution**: Developed a real-time voice receptionist that conducts low-latency, natural telephone conversations in English and Telugu, screens callers, takes structured messages, and executes tool calls.
- **Architecture**:
  - Transport-agnostic `AudioStreamBridge` handling 16kHz inbound and 24kHz outbound Linear PCM audio.
  - VAD barge-in interruption detection that immediately flushes output audio buffers on caller speech.
  - Cryptographic session authentication with single-use HMAC-SHA256 tokens and replay attack protection.
  - Function calling pipeline with atomic, collision-safe file persistence (`0o600` permissions).
- **Quality**: 58 automated unit & integration tests passing (`pytest`), containerized with non-root Docker UID 10001, and deployed on Render.
- **Stack**: `Python 3.12`, `FastAPI`, `WebSockets`, `Google Gemini Live`, `Pydantic v2`, `Docker`, `Pytest`.

### 2. [MedGuard AI](https://github.com/manishvarma2972-stack/MedGuard) &bull; Pharmacy Operating System & Public Medicine Discovery
*Full-stack retail pharmacy operating system with multimodal AI packaging OCR and FEFO inventory tracking.*

- **Problem**: Retail pharmacies struggle with medicine expiry waste, manual catalog entry errors, and disconnected stock visibility for patients seeking urgent drugs.
- **Solution**: Built an end-to-end pharmacy platform that automates medicine intake via multimodal computer vision, enforces First-Expired First-Out (FEFO) dispensing, guarantees atomic race-free checkout, and enables geospatial patient medicine discovery.
- **Architecture**:
  - Server-side Gemma 4 / Gemini Vision OCR pipeline for pharmaceutical packaging text and expiry extraction.
  - ACID transactional checkout engine preventing overselling across concurrent retail transactions.
  - Geospatial Haversine radar calculating distance to stocked pharmacies for nearby patients.
  - Dynamic piece-and-strip inventory derivation from an immutable stock movement audit ledger.
- **Quality**: Complete Pytest test suite, end-to-end simulated customer-to-invoice integration flows, and automated PDF tax invoice archiving.
- **Stack**: `FastAPI`, `React 18`, `TypeScript`, `PostgreSQL / Neon`, `Alembic`, `Tailwind CSS`, `ReportLab`.

### 3. [MediRoutine](https://github.com/manishvarma2972-stack/mediroutine) &bull; Local-First Sequential Medication Companion
*Offline-first Flutter mobile application with dynamic sequential dose timing and Android 16 exact alarms.*

- **Problem**: Standard reminder apps fire all alarms at arbitrary fixed clocks, failing patients whose medicine regimens require sequential intervals (e.g., Dose B strictly 30 minutes after Dose A is consumed).
- **Solution**: Engineered a local-first medication manager featuring confirmation-driven sequential reminder engines, persistent local state, and full bilingual accessibility in English and Telugu.
- **Architecture**:
  - Confirmation-driven timing calculations scheduling subsequent doses based on real taken timestamps.
  - Drift SQLite reactive persistence preserving full schedule state across device reboots (`RECEIVE_BOOT_COMPLETED`).
  - Native Android 16 exact alarm scheduling with manufacturer-specific (Samsung/Xiaomi) deep sleep mitigation guides.
  - Native internationalization (`l10n`) supporting English and Telugu with responsive typography scaling.
- **Quality**: 30 automated Flutter tests covering database persistence, sequential timing logic, and Telugu accessibility.
- **Stack**: `Flutter 3`, `Dart`, `Drift SQLite`, `Riverpod`, `flutter_local_notifications`, `Android SDK`.

## 🏛️ Engineering Standards & Practices

| Principle | Implementation |
| :--- | :--- |
| **Local-First & Offline-Ready** | SQLite / Drift database persistence ensures mobile applications remain fully functional without active network connectivity. |
| **Concurrency & ACID Transactions** | PostgreSQL atomic updates and single-use HMAC token invalidation eliminate double-spending, overselling, and replay vulnerabilities. |
| **Real-Time Streaming** | Bidirectional low-latency WebSockets with queue-flushing interrupt handlers ensure seamless human-AI conversational pacing. |

| **Automated Testing** | Comprehensive automated suites verify edge cases, timezones, reboots, database migrations, and accessibility. |
